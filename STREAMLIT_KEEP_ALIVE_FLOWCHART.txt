================================================================================
          STREAMLIT APP KEEP-ALIVE WORKFLOW (OPTION 1)
================================================================================

[ 1. Streamlit Default Behavior ]
       |
       v
+-------------------------------+
| App inactive for 7 days       |
+-------------------------------+
       |
       v
+-------------------------------+
| Streamlit puts app to sleep   |
| (Shows "App gone to sleep")   |
+-------------------------------+

--------------------------------------------------------------------------------

[ 2. Automated Solution with GitHub Actions ]

+-------------------------------------------------------------+
| GitHub Action: .github/workflows/keep_alive.yml             |
| Schedule: Runs automatically every 5 days ('0 0 */5 * *')   |
+-------------------------------------------------------------+
       |
       v
+-------------------------------------------------------------+
| Executes: curl -sS https://YOUR_APP_URL                      |
| Sends an HTTP GET request to your deployed Streamlit app      |
+-------------------------------------------------------------+
       |
       v
+-------------------------------------------------------------+
| Streamlit registers active traffic                            |
| Timer resets -> App stays ALIVE continuously               |
+-------------------------------------------------------------+
